How to interpret

The PPO action is a policy output; TCP window growth can also occur between decision intervals. A “Maintain” action does not imply that CWND remains constant for the entire simulation.

Prototype limitation

The current dashboard visualizes saved experiment outputs; it does not launch a new ns-3 simulation from the browser. Runtime features and training features are not perfectly aligned in the current prototype, so results should be interpreted as experimental rather than production-ready.
